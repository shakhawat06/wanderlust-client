# AGENTS.md

Next.js 16 (App Router) app in `src/app`. No backend, tests, or CI yet — the app is UI scaffolding via shadcn/ui.

## Commands

- `npm run dev` — dev server (verify changes; caches types in `.next/dev`)
- `npm run lint` — runs plain `eslint` (flat config in `eslint.config.mjs`; `next lint` was removed in Next 16)
- `npx tsc --noEmit` — typecheck (no npm script). Requires types generated by a `dev`/`build` run first (`tsconfig` includes `.next/dev/types` and `.next/types`)
- `npm run build` — production build. There is no CI or test suite; verify with `lint` + `tsc --noEmit` before declaring done

## Known failing lint in generated code

`npm run lint` currently reports 2 pre-existing errors (react-hooks `set-state-in-effect`) in `src/components/ui/carousel.tsx` and `src/hooks/use-mobile.ts`. These are upstream shadcn-generated files — don't assume your changes caused them, and don't "fix" them casually.

## Toolchain quirks

- **`cacheComponents: true`** in `next.config.ts` — any uncached dynamic data (fetch, DB, cookies) must be inside a Suspense boundary or `use cache`, or the build will error. Read the cacheComponents guide in `node_modules/next/dist/docs/` before touching data fetching.
- **`reactCompiler: true`** — React handles memoization automatically; don't add hand-rolled `useMemo`/`React.memo`. Lint enforces strict hooks rules (see errors above).
- **Tailwind v4** — CSS-first, no `tailwind.config.js`. Theme tokens live via `@theme inline` / CSS variables in `src/app/globals.css`. CSS is wired through a custom Turbopack rule in `next.config.ts` (`@tailwindcss/turbopack`), not the normal imports.
- Path alias `@/*` → `./src/*` (see `tsconfig.json`).

## shadcn/ui

- Config in `components.json`, style `base-nova`. Primitives come from **`@base-ui/react`, not Radix** — APIs differ from the shadcn components in your training data; check what actually exists in `src/components/ui/*` before writing code that uses them.
- Add new components with `npx shadcn add <name>` rather than hand-writing them into `src/components/ui/`.
